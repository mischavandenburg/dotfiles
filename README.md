# Mischa's Dotfiles

My dotfiles are not publicly available any longer.

As my setup grew in complexity, I was tired of the overwhelming amount of questions that came my way from the public.

My entire setup has developed into a fully OS-independent workflow based on dev containers: Dev Containers and DevPod for the environment, chezmoi for the dotfiles, mise for the tools, zsh, tmux and Neovim inside.

If you want to learn this workflow, it is taught in full inside KubeCraft, and members get access to my complete dotfiles repo, which is now private.
